# Cognition Protocols

Cognition Protocols occupy the agent cognitive layer, **L9**, above the L8 agent
transports. They provide primitives for coordination and consensus across a
population of agents — establishing shared intent before work begins, and
reconciling decisions where agent roles diverge.

The two protocols are **ACCORD** (intent alignment) and **CONCORD** (deciding under
conflict). Both are open specifications, distributed as agent skills, and designed
to be inserted into an existing multi-agent system without modifying the application.
